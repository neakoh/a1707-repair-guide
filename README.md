# Top case transplant: MacBook Pro 15" Touch Bar (A1707)

A step-by-step guide to moving the logic board, display and Touch ID button from an old MacBook Pro 15" (2016–2017, A1707) into a replacement top case, with Touch ID still working afterwards. Screw maps, a "connect and test before screwing down" rebuild, and the Touch ID transfer, which no other written guide covers.

**Read it online:** the site is published from this repository.

## What it covers

Replacement top cases that arrive with the fans, battery, speakers, trackpad, battery board and microphone already fitted. Moving those parts into a bare shell isn't covered yet.

## Contributing

Corrections and new steps are welcome, by issue or pull request.

- The guide is `guide.json`: each step has a `title`, `text` (Markdown), `images`, `parts` (screws that come out), `warning` and `check`.
- Screw maps and diagrams are SVGs in `maps/`.
- Open `index.html` through any local web server (for example `python3 -m http.server`) to see your change.

Especially wanted: the steps for moving the fans, battery, speakers, trackpad, battery board or microphone into a shell that arrives without them.
